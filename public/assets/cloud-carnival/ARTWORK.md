# Cloud Carnival artwork

The carousel, sculpted horses, curved carnival booths, wind-up airship, balloon fleet, decorated gateway, floating-island geometry, waterfall tunnel, ceramic road material and cloud-bank shader were authored for Palm Prix. These are original assets; no Nintendo models, artwork, sounds or textures were used.

`cloud-panorama.png` is an original AI-generated sky painting, created with the built-in imagegen tool on 24 October 2026. It is project artwork, not part of the third-party CC0 texture pack.

Generation prompt:

Use case: stylized-concept. Asset type: seamless equirectangular 360-degree sky panorama texture, 4096x2048 target 2:1 aspect, for an original high-end stylized 3D kart racing game called Cloud Carnival. Paint ONLY sky and clouds. Wide bright azure upper sky, luminous sculpted cumulus cloud mountain banks along the lower half, tiny remote whimsical floating islets with elegant pale mint cliffs and golden-roofed spires very far away near the horizon. The horizon is across the middle of the image. Warm sunrise light from upper left, soft lavender cloud shadows, pearly ivory cloud tops, saturated rich blues and peach/gold highlights. Premium hand-painted game environment art, breathtaking depth and magical whimsical color, beautifully layered voluminous cloud masses, clear blue open upper half. The left and right edges must tile seamlessly, continuous panoramic cloud band. No close foreground, no road, no cars, no characters, no logos, no text, no watermarks, no visible sun disk. Intended for a sky sphere viewed from inside. Only sky with clouds and extremely distant floating islets, not concept art of the playable track. Detailed softly painterly materials, crisp and clean, no generic low-poly geometry.
